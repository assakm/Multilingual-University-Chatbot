# Multilingual University Information Chatbot

## About the Project
The Multilingual University Information Chatbot helps students and university visitors quickly find information about university services, academics, admissions, examinations, and other frequently asked questions.

The chatbot is designed to provide information in multiple languages and reduce the time users spend searching for university details.

## Key Features
- Multilingual question answering
- Retrieval-Augmented Generation (RAG)
- FAQ matching with fuzzy search
- Semantic search for relevant information
- Flask-based web application
- Chat interface and admin interface

## Technologies Used
- Python
- Flask
- Retrieval-Augmented Generation (RAG)
- ChromaDB
- Sentence Transformers
- RapidFuzz
- HTML, CSS, and JavaScript

## Project Structure
- `app.py` — Main application
- `services/` — Chatbot and retrieval services
- `templates/` — HTML templates
- `static/` — CSS and JavaScript files
- `data/faq.json` — FAQ data
- `requirements.txt` — Python dependencies

## Setup
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the required environment variables in a local `.env` file.
5. Follow the application's configuration requirements and run the Flask application.

## Security
Do not commit API keys, passwords, or other secrets to the repository.
